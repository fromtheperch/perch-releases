# perch

perch is a free Mac app that shows every Claude Code and Codex session you have running, sorted by what each needs, so you can answer them from one place or from your phone.

perch isn't available to download yet. [Get notified at launch](https://theperch.dev/#waitlist).

How it works and how to set it up: [theperch.dev/docs](https://theperch.dev/docs/).

## Report a problem or ask for something

[Open an issue](https://github.com/fromtheperch/perch-releases/issues/new/choose). For a problem, **Settings → Problems → Copy for a bug report** in perch gives you a summary to paste, with keys, email addresses, repos and folder names left out.

For a security problem, don't open an issue: see [SECURITY.md](SECURITY.md).
