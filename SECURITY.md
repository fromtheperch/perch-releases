# Security

If you find a security problem in perch, please report it privately: use [Report a vulnerability](https://github.com/fromtheperch/perch-releases/security/advisories/new) on this repository. Don't open a public issue.

Say which version you're on (perch → About) and how to reproduce it. You'll get an answer within a few days.

What perch keeps and sends is described in [Privacy](https://theperch.dev/docs/privacy/) and [Security](https://theperch.dev/docs/security/).
